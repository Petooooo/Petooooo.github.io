2023년 5~6월에는 **Verilog로 만든 게임 「Escape From the Dark」를 DE2 FPGA 보드의 VGA 화면에 출력했다.** 화면에 무언가를 그리는 간단한 작업처럼 보이지만, FPGA에서는 게임 상태를 바꾸는 일과 화면의 픽셀을 정확한 타이밍에 내보내는 일을 함께 설계해야 했다.

처음 하드웨어 설계를 공부하면서, 소프트웨어처럼 필요할 때 화면을 다시 그리는 방식과 **클럭에 맞춰 디스플레이 신호를 계속 만드는 방식**이 얼마나 다른지 경험한 프로젝트였다.

이 글은 2023년 프로젝트를 2026년 11월에 정리한 회고 기록이다.

## VGA 출력의 타이밍

VGA 출력에서는 픽셀의 가로·세로 위치를 따라가며 화면에 표시할 색을 결정한다. 보이는 화면 영역뿐 아니라 동기화 신호와 Blanking 구간도 다뤄야 한다.

{{figure /figures/journals/fpga-vga-game-pipeline.svg | Verilog 게임 상태와 VGA 스캔 위치를 이용해 픽셀을 출력하는 구조를 나타낸 개념도다.}}

이 과정에서 **화면을 갱신하는 타이밍**과 **현재 게임이 어떤 상태인지**를 분리하는 일이 중요했다. 게임 상태가 바뀌었다고 VGA 출력이 임의의 시점에 멈출 수는 없다.

## 클럭 기반 게임 로직

Verilog로 게임 상태와 출력 로직을 설계하고, DE2 보드에서 VGA로 결과를 보여주도록 만들었다. 게임에서 보이는 장면은 내부 상태와 현재 스캔 중인 픽셀 위치를 기준으로 결정했다.

그렇기 때문에 게임 규칙을 구현하는 것과 별개로, 각 신호가 어느 클럭에서 바뀌는지 확인해야 했다. 하나의 RTL 설계 안에서도 상태를 저장하는 순차 논리와 화면을 계산하는 조합 논리의 역할이 달랐다.

## 구현 결과

**Verilog·FPGA 기반 게임을 DE2 보드에서 실제 VGA 화면으로 출력**했다. 당시 코드나 보고서에서 게임 입력 배선과 리소스 사용량을 다시 확인할 수 없으므로, 구체적인 버튼 수와 동작 속도를 임의로 적지는 않았다.

이후 5단계 RISC CPU나 Systolic Array, CNN 가속기를 설계할 때도 클럭과 데이터 경로를 중심으로 생각하는 바탕이 됐다.
