In May–June 2023, I built **Escape From the Dark**, a VGA-output game implemented in **Verilog on a DE2 FPGA board**. It was an early project in which the visible result depended on hardware timing as much as on application logic.

Unlike software that can draw a screen whenever its event loop is ready, a basic FPGA VGA design has to produce video information on a predictable pixel and line schedule.

*This retrospective was prepared in November 2026 from the earlier project/CV record. The date refers to the original project, not to publication of the article.*

## Video timing is part of the design

A VGA controller advances through pixel positions and line intervals with synchronization and blanking periods. Game graphics must be selected according to that scan position and the current game state.

The main design challenge was separating **the timing that drives the display** from **the state that describes the game**. Updating game state and generating the video signal are related operations, but they should not be confused.

## Game state in synchronous logic

I implemented the game logic as an RTL design, using clocked state transitions to control what appeared on the VGA output. The board supplied the hardware execution environment; the logic described how state and rendered output changed over time.

The design therefore connected three concerns: the current input/game state, the state transition at a clock boundary and the pixel output derived from that state.

## Result

The finished 2023 project was a **Verilog FPGA game displayed through VGA on DE2 hardware**. I have retained it as a compact digital-design example because it shows a working end-to-end path from RTL state to a user-visible output.

The remaining historical material does not give a complete input-interface specification or a reproducible FPGA timing report, so I have not invented game rules, control wiring or device utilization figures.
